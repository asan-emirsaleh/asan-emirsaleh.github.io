# PKM-01

Презентация: /talks/pkm-01/. 21 слайд.

Текстовая основа: PROJECTS/author-lectures/PKM-01/Презентация — От информации к знанию.md.

Оформление продолжает предыдущие доклады сайта: белый фон, тёмный текст, бордовый акцент. Все зависимости находятся рядом с презентацией.

Стрелки и пробел — переход, Esc — обзор, F — полный экран. Клик по изображению открывает его крупно.

В презентации нет заметок докладчика.

После изменения заметки обновить презентацию и проверить сборку:

```sh
python3 scripts/sync_pkm.py
hugo --minify --baseURL https://asan-emirsaleh.github.io/
```

Для синхронизации нужны Python 3 и Pandoc. Исходная заметка только читается.
Путь можно указать через `--source`. При публикации используется существующий workflow GitHub Pages.

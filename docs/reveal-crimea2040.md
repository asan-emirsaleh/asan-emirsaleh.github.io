# Презентация Qırım 2040 в Hugo

Адрес страницы после публикации: `https://asan-emirsaleh.github.io/talks/crimea2040-01/`.

## Где править текст

Текст слайдов хранится в Obsidian в файле `PROJECTS/author-lectures/launch/2026-09-25/Презентация — Нация не процент в ДНК-тесте.md`. Старый `Черновик презентации.md` сохранён отдельно. Строка `___` отделяет слайды. Иллюстрации лежат в соседней папке `attachments` и упоминаются в Markdown как `![описание](attachments/имя-файла)`.

`content/talks/crimea2040-01/index.md` создаётся скриптом из этого файла Obsidian. Его текст не следует редактировать вручную: следующая синхронизация заменит правки. Репозиторий хранит копию готового HTML и иллюстраций, поэтому GitHub Pages собирает презентацию без доступа к личному хранилищу Obsidian.

## Первое открытие на ноутбуке

1. Установить Git, Hugo Extended, Python 3 и Pandoc. ImageMagick нужен для автоматической обрезки прозрачных полей изображения с понятиями происхождения; если его нет, скрипт использует исходное изображение. Для просмотра уже собранной презентации Pandoc и ImageMagick не нужны.
2. Склонировать сайт вместе с темой: `git clone --recurse-submodules https://github.com/asan-emirsaleh/asan-emirsaleh.github.io.git`.
3. Перейти в папку репозитория: `cd asan-emirsaleh.github.io`.
4. Найти локальную копию файла презентации в Obsidian. При необходимости передать её путь скрипту:
   `python3 scripts/sync_crimea2040.py --source "/полный/путь/к/Презентация — Нация не процент в ДНК-тесте.md"`.
5. Собрать сайт командой `hugo` или запустить `hugo server` для просмотра по адресу, который он напечатает. Путь презентации после адреса сервера: `/talks/crimea2040-01/`.
6. После проверки сохранить в Git изменения в `content/talks/crimea2040-01/index.md` и `static/talks/crimea2040-01/assets/` вместе с другими намеренными правками. Публикация происходит после отправки изменений в ветку `main`.

Если файл Obsidian ещё не менялся, достаточно шагов 1–3 и `hugo`: готовая версия уже находится в репозитории.

## Как устроена изоляция

Страница использует отдельный шаблон `layouts/_default/reveal.html`. Reveal.js и стиль `static/talks/crimea2040-01/deck.css` подключаются только на этой странице. Виджет генетического дрейфа загружается внутри iframe на слайде 13; обычные страницы сайта не загружают его JavaScript. Номер слайда и стрелки Reveal располагаются поверх полноэкранного iframe. В локальной проверке переходы и кнопка «Запустить» виджета работали.

Локальный набор файлов презентации занимает около 3,3 МБ, в основном за счёт изображений; это не добавляется к загрузке обычных страниц сайта. Перед публичной публикацией коллажа из проекта Натальи Ивановой «Национальные истоки красоты» нужно проверить право на воспроизведение самого изображения; источник указан на слайде: https://www.thevoicemag.ru/beauty/face/kazhdaya-zhenshchina-prekrasna-rossiyskiy-fotograf-predstavila-unikalnyy-proekt/.

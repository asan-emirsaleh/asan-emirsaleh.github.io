# Sudaq şive dili: презентация для Reveal.js / Hugo

Страница сайта: `/talks/sudaq-2026/`. 23 слайда, 18 разных аудиофайлов. Оформление продолжает предыдущую лекцию Qırım 2040: белый фон, тёмный текст, бордовый акцент, формат 1280 × 720.

## Просмотр

Запустить `hugo server`, затем открыть `/talks/sudaq-2026/` по адресу сервера.

Стрелки / пробел — переход между слайдами. Esc — обзор слайдов. F — полный экран. N — заметки к текущему слайду; Esc закрывает заметки. Клик по иллюстрации открывает её крупно, Esc закрывает изображение. Аудио запускается кнопкой проигрывателя. При переходе на другой слайд запись останавливается и возвращается к началу. Одновременно играет только один фрагмент.

Все изображения, аудио, шрифт IPA и Reveal.js входят в локальный комплект. Интернет нужен только для перехода к внешним источникам. В комплекте для переноса открыть `index.html`; папки `assets` и `vendor` и файлы `deck.css`, `deck.js` должны оставаться рядом с ним. Ссылки на список докладов и полный датасет работают в составе сайта.

## Текст и обновление

Исходная основа:
`PROJECTS/author-lectures/taraqtaş_2026/лекция Sudaq şive dili - tarixımızdan bir menbadır.md`

Скрипт читает основу и изображения из соседней папки `files`, а транскрипции, написания и аудио — из `content/data/data1/` в сайте. Он не пишет в Obsidian.

```bash
python3 scripts/sync_sudaq.py
hugo
```

Если хранилище на другом компьютере:

```bash
python3 scripts/sync_sudaq.py --source "/полный/путь/к/основе.md"
```

Для обновления требуется Python 3 и Pandoc. Для сборки уже подготовленной версии нужен только Hugo; для просмотра автономного HTML Hugo не требуется.

Скрипт создаёт `content/talks/sudaq-2026/index.md`. В нём находятся обычный HTML слайдов и `<aside class="notes">` с заметками. Правки в этом файле непосредственно меняют слайды, но следующая синхронизация заменяет его содержимое. Порядок и редакторские вставки задаются в `scripts/sync_sudaq.py`; большие изменения структуры основы требуют соответствующей правки скрипта.

Отдельный шаблон `layouts/_default/reveal-sudaq.html` и файлы `static/talks/sudaq-2026/` не затрагивают предыдущую презентацию и обычные страницы сайта. Аудиофрагменты имеют три колонки: написание, транскрипция, проигрыватель. Происхождение записей сохранено в ресурсе `audio-sources.tsv` и исходном датасете, без колонки источника на слайдах.

## Редакторские решения и ссылки

- Судакский текст и фонетические транскрипции взяты из основы и датасета. В слове `coydum` использована орфографическая форма датасета; в плане было `coydım`.
- В фонетических примерах с `qʷoz` заголовок дополнен `qʷ`; добавлен пример `kʷʰot kʷʰot`, чтобы отдельно проиллюстрировать указанное в плане `kʷ`.
- Система имён показана полностью, в двух таблицах по семь строк. Таблица согласных показана полностью, в двух таблицах по восемь строк. Все десять словесных сопоставлений и семь примеров с `o` сохранены.
- Убрано определение «арабский» для Рашида ад-Дина. Сведения об авторе и труде: [Encyclopaedia Iranica, Jāmeʿ al-tawāriḵ](https://www.iranicaonline.org/articles/jame-al-tawarik/). Эта ссылка не подтверждает конкретный фрагмент о Таткаре: его издание и страницу ещё нужно указать.
- Утверждение о другом языковом происхождении имён передано как возможность. Сходство форм требует отдельной этимологической проверки. В сравнительной таблице знак «−» пояснён как отсутствие отметки в рабочей схеме, а не отсутствие звука во всех тюркских языках.
- На карте совмещены разновременные языки и гипотетические классификации. Она подписана как обзорная схема, а не точная карта одного периода. Авторский файл карты сохранён.
- Схема гласных `vowels.svg` редактируемая; красным (qırmızlı) выделены только судакские [ɑː], [ɐ], [ə], синим [a], [ɯ] из основы. Это схема артикуляции, а не результат акустических измерений и не полный инвентарь языка. Оси и положение символов сверены с [таблицей гласных International Phonetic Association](https://www.internationalphoneticassociation.org/content/ipa-vowels).
- Для археологических рисунков 12 и 14 в основе нет полной библиографической ссылки. Для родовых имён указан источник из заметки: Чалаш Сейтосман, «Suvdağ ses», 1999, № 12. Более подробные оговорки и ссылки находятся в заметках докладчика.

Публикация на сайт выполняется обычным способом после просмотра презентации. Публикация выполняется существующим GitHub Actions workflow при отправке коммита в main.
